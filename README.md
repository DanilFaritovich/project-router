# ProjectRouter

[English](README.md) · [Русский](README.ru.md)

ProjectRouter is the planned bilingual engineering portfolio of Danil Miftakhov:
projects, developer tools and resume documents in one static website.

The initial repository preserves the original [design references](design/reference/README.md)
and establishes code licensing. Development standards and the architecture plan
will be delivered through the Stage 01 Bootstrap Pull Request into `develop`.
No application, package dependencies or deployment configuration exists yet.

The target stack is Vue 3, TypeScript, Vite, Tailwind CSS, Vue Router and Vue I18n,
with SSG/prerendering, PDF.js, Vitest and Playwright planned for later stages.
There is no dedicated backend or database.
