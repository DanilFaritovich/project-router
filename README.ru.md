# ProjectRouter

[English](README.md) · [Русский](README.ru.md)

ProjectRouter — планируемое двуязычное инженерное портфолио Данила Мифтахова:
проекты, инструменты разработчика и резюме на одном статическом сайте.

Начальный репозиторий сохраняет исходные [дизайн-референсы](design/reference/README.md)
и определяет лицензию кода. Стандарты разработки и архитектурный план поступят
через Pull Request Stage 01 Bootstrap в `develop`.
Приложения, npm-зависимостей и конфигурации развёртывания пока нет.

Целевой стек: Vue 3, TypeScript, Vite, Tailwind CSS, Vue Router и Vue I18n.
SSG/Prerender, PDF.js, Vitest и Playwright запланированы на следующие этапы.
Собственного backend и базы данных нет.

Код доступен по [MIT](LICENSE), включая коммерческое использование.
[Ограничения для персональных материалов и идентичности](ASSETS-LICENSE.md)
действуют отдельно.
